SIGNFORGE backend (FastAPI) for the GitHub Pages frontend. It starts with the public INCLUDE and ASL datasets and labelled
DEMO DATA only. There is no login: anything created or deleted here is visible to everyone, and the disk resets when the
Space restarts. Not a validated sign-language corpus. Source: https://github.com/bhaveshlakhmani25-ui/signforge
