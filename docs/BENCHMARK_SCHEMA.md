# SIGNFORGE Benchmark Output Schema

**Schema Version:** `signforge-benchmark-v1`  
**Author:** ML & Evaluation Engineering (Ruben Raju)  
**Consumer:** Benchmark Page & Evaluation Visualizations (Bhavesh Lakhmani)  
**Status:** Aligned Specification (Step 1 Deliverable — Pre-Implementation)

---

## 1. Overview & Architecture

This document defines the versioned JSON contract for benchmark artifacts generated by the SIGNFORGE simulation harness.

### Architecture & Delivery Contract
- **Offline Batch Generation:** The benchmark is produced by an offline benchmark script (`backend/scripts/run_benchmark.py`). It outputs a single standalone JSON file to `data/benchmark_results.json` along with a human-readable before/after summary printed to the terminal.
- **Frontend Consumption:** Bhavesh's benchmark view (`frontend/app/models/` or a dedicated benchmark component) reads this JSON directly. No new interactive FastAPI API endpoint is introduced unless requested and approved by Tashvi.
- **Honesty by Design:** Missing or unverified attributes (such as unauthenticated signer IDs or unobserved validation folds) are serialized as `null` with machine-readable warnings, rather than being populated with zeros or synthetic numbers.
- **Source Type Contract Alignment:** In benchmark artifacts, the source designation is `external_dataset`. Because `frontend/lib/api.ts` currently enumerates `source: "captured" | "public_dataset" | "demo_fixture"`, we document this distinction for Tashvi and Bhavesh: if benchmark records are ever written to the application database, either expand the frontend type definition or map to `"public_dataset"` with a clear provenance note.

## 2. Field Specifications

### 2.1 Top-Level Properties

| Field | Type | Required | Nullable | Description |
|---|---|---|---|---|
| `schema_version` | `string` | **Yes** | No | Constant `"signforge-benchmark-v1"`. |
| `generated_at` | `string` | **Yes** | No | ISO 8601 UTC timestamp of benchmark completion. |
| `dataset` | `object` | **Yes** | No | Provenance, source type, and vocabulary details. |
| `splits` | `object` | **Yes** | No | Official split metadata, split hashes, and independence status. |
| `protocol` | `object` | **Yes** | No | Experimental budget, rounds, seeds, and validation proxy configuration. |
| `model` | `object` | **Yes** | No | Model architecture, hyperparameters, and feature contract versions. |
| `summary` | `object` | **Yes** | No | High-level before/after comparisons and aggregate win/loss metrics. |
| `curves` | `object` | **Yes** | No | Metric progression by round and acquisition budget for each strategy. |
| `runs` | `array` | **Yes** | No | Detailed run records for each seed, strategy, and acquisition round. |
| `warnings` | `array of string` | **Yes** | No | Documented limitations, scope adjustments, or unverified attributes. |

---

### 2.2 `dataset` Object

| Field | Type | Required | Nullable | Description |
|---|---|---|---|---|
| `name` | `string` | **Yes** | No | Dataset name (e.g. `"INCLUDE"`). |
| `version` | `string` | **Yes** | No | Release tag or commit identifier. |
| `source_type` | `string` | **Yes** | No | Set to `"external_dataset"`. Never `"captured"` or `"demo_fixture"`. |
| `language` | `string` | **Yes** | No | Target language (e.g. `"Indian Sign Language"`). |
| `sign_classes` | `array of string` | **Yes** | No | Canonical gloss list of selected vocabulary (10–20 signs). |
| `num_classes` | `integer` | **Yes** | No | Length of `sign_classes`. |
| `total_samples` | `integer` | **Yes** | No | Total non-test + test samples in the evaluated subset. |
| `samples_per_class` | `object` | **Yes** | No | Mapping of sign gloss to total sample count in the benchmark subset. |

---

### 2.3 `splits` Object

| Field | Type | Required | Nullable | Description |
|---|---|---|---|---|
| `strategy` | `string` | **Yes** | No | `"official_include_test_split"` (or `"proposed_stratified_fallback"` if official files cannot be mapped). |
| `signer_independent` | `boolean` | **Yes** | No | `false` (honesty rule: INCLUDE signer IDs are unverified). |
| `signer_ids_available` | `boolean` | **Yes** | No | `false` if verified per-clip signer IDs are absent. |
| `official_split_reference` | `string` | **Yes** | Yes | File or commit reference to official train/test CSV (e.g. `"INCLUDE/test.csv"`), or `null`. |
| `frozen_test_hash` | `string` | **Yes** | No | SHA-256 hash of frozen test sample IDs. |
| `train_pool_hash` | `string` | **Yes** | No | SHA-256 hash of training/candidate pool sample IDs. |
| `test_sample_count` | `integer` | **Yes** | No | Total sample count in the frozen official test set. |
| `candidate_pool_count`| `integer` | **Yes** | No | Total sample count in the initial unlabeled candidate pool $\mathcal{U}_0$. |

---

### 2.4 `protocol` Object

| Field | Type | Required | Nullable | Description |
|---|---|---|---|---|
| `strategies` | `array of string` | **Yes** | No | `["signforge", "round_robin", "random"]`. |
| `seeds` | `array of integer` | **Yes** | No | Evaluation seeds executed (e.g. `[42, 43, 44, 45, 46]`). |
| `initial_samples_per_class` | `integer` | **Yes** | No | Starting labeled count $N_0$ per sign in $\mathcal{D}_0$ (e.g. `2`). |
| `num_rounds` | `integer` | **Yes** | No | Number of acquisition rounds $R$ (e.g. `25`). |
| `batch_size_per_round` | `integer` | **Yes** | No | Total newly acquired samples $B$ per round across all classes (e.g. `2`). |
| `uncertainty_proxy` | `object` | **Yes** | No | Validation-fold error estimation configuration. |

#### `protocol.uncertainty_proxy` Object
| Field | Type | Required | Nullable | Description |
|---|---|---|---|---|
| `method` | `string` | **Yes** | No | `"k_fold_cross_validation_error"`. |
| `num_folds` | `integer` | **Yes** | No | Number of validation folds $K$ (e.g. `3` or `5`). |
| `metric` | `string` | **Yes** | No | Per-class error proxy: `"1_minus_recall"`. |
| `missing_class_fallback` | `string` | **Yes** | No | Policy when class has 0 validation instances: `"null_unavailable"`. |
| `labeled_as_predictive_entropy` | `boolean` | **Yes** | No | Must be `false` (validation error is not predictive entropy). |

---

### 2.5 `model` Object

| Field | Type | Required | Nullable | Description |
|---|---|---|---|---|
| `architecture` | `string` | **Yes** | No | `"GRUClassifier"`. |
| `feature_schema_version` | `string` | **Yes** | No | `"mp-holistic-75-xyz-v1"`. |
| `input_keypoints` | `integer` | **Yes** | No | `27` (OpenHands minimal-27 subset). |
| `input_frames` | `integer` | **Yes** | No | `30` frames. |
| `input_fps` | `number` | **Yes** | No | `10.0` FPS. |
| `hidden_dim` | `integer` | **Yes** | No | `64`. |
| `epochs` | `integer` | **Yes** | No | `80`. |
| `learning_rate` | `number` | **Yes** | No | `0.001`. |
| `weight_decay` | `number` | **Yes** | No | `0.0001`. |
| `pretrained` | `boolean` | **Yes** | No | `false` (from-scratch baseline). |

---

### 2.6 `summary` Object (Before / After Comparison)

| Field | Type | Required | Nullable | Description |
|---|---|---|---|---|
| `initial_budget` | `integer` | **Yes** | No | Total initial training samples ($N_0 \times \text{num\_classes}$). |
| `final_budget` | `integer` | **Yes** | No | Total final training samples after all rounds ($|\mathcal{D}_0| + R \times B$). |
| `initial_metrics` | `object` | **Yes** | No | Mean and std across seeds at Round 0: `{ "accuracy_mean", "accuracy_std", "macro_f1_mean", "macro_f1_std" }`. |
| `by_strategy` | `object` | **Yes** | No | Keyed by strategy name (`"signforge"`, `"round_robin"`, `"random"`). |

#### `summary.by_strategy.<strategy>` Object
| Field | Type | Required | Nullable | Description |
|---|---|---|---|---|
| `final_accuracy_mean` | `number` | **Yes** | No | Mean Top-1 accuracy on frozen test set at Round $R$. |
| `final_accuracy_std` | `number` | **Yes** | No | Standard deviation of Top-1 accuracy across seeds. |
| `final_macro_f1_mean` | `number` | **Yes** | No | Mean Macro-F1 on frozen test set at Round $R$. |
| `final_macro_f1_std` | `number` | **Yes** | No | Standard deviation of Macro-F1 across seeds. |
| `macro_f1_gain_mean` | `number` | **Yes** | No | Mean gain over baseline: $\text{final} - \text{initial}$. |
| `samples_added` | `integer` | **Yes** | No | Total newly acquired samples ($R \times B$). |

---

### 2.7 `curves` Object (Charting Artifact)

| Field | Type | Required | Nullable | Description |
|---|---|---|---|---|
| `x_axis_label` | `string` | **Yes** | No | `"Newly Acquired Samples"`. |
| `points_per_strategy`| `object` | **Yes** | No | Keyed by strategy name. Contains array of round evaluation points. |

#### Points in `curves.points_per_strategy.<strategy>` Array
```json
{
  "round": 0,
  "acquired_samples": 0,
  "total_training_samples": 20,
  "accuracy_mean": 0.352,
  "accuracy_std": 0.021,
  "macro_f1_mean": 0.318,
  "macro_f1_std": 0.024
}
```

---

### 2.8 `runs` Array (Audit Trail)
Contains individual records for each `(seed, strategy, round)` execution, including per-class metrics, confusion matrices, fold support diagnostics, and the specific candidate samples acquired.
